# AI-driven Project Management Tool

This is a full-stack project management application powered by AI suggestions. It features role-based access for Admin, Project Manager, and Developer, and uses Material-UI for a modern interface.

## Features
- User authentication and role management such as Developer, ProjectManager and Admin
- Project and task CRUD operations
- Kanban board for task visualization
- AI-powered task assignment and suggestions (Gemini API)
- Responsive UI with Material-UI
- Three dashboards: Admin, Project Manager, Developer
- User management feature in Admin dashboard
- Developers can update their task status from their dashboard
- RESTful backend (Node.js + Express)
- MongoDB database
